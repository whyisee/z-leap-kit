# 织络（TraceWeave）

织络是一个由用户主动记录、经 AI 结构化并由用户确认后入账的全域生活流水账。项目内部代码名为 TraceWeave，采用前后端分离的 npm workspace。

## 工程结构

```text
trace-weave/
├── frontend/            # React + Vite Web 应用
├── backend/             # Fastify API、领域服务和数据库迁移
│   ├── migrations/      # PostgreSQL 迁移
│   └── src/server/
├── doc/                 # 产品与架构设计
└── package.json         # workspace 编排脚本
```

## 本地启动

环境要求：Node.js、npm、PostgreSQL。

```bash
cp backend/.env.example backend/.env
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

- Web：http://127.0.0.1:5173
- API：http://127.0.0.1:8787
- 健康检查：http://127.0.0.1:8787/api/health

数据库配置只放在 `backend/.env`，该文件已被 Git 忽略。迁移只操作 `DB_SCHEMA` 指定的 Schema。

### DeepSeek 配置

真实 AI 解析只在后端调用 DeepSeek，Key 不能写入前端代码：

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_TIMEOUT_MS=45000
DEEPSEEK_MAX_RETRIES=2
```

修改后运行 `npm run restart`。访问 `/api/health`，确认返回的 `ai.configured` 为 `true`。如需显式使用本地开发规则解析器，可将 `AI_PROVIDER` 改为 `mock`；页面会明确标注“非 AI”。

DeepSeek 请求使用官方 `/chat/completions` 接口和 JSON Output。系统只发送用户主动提交的文字、记录时间与时区，不发送图片、视频附件或完整生活历史。模型结果必须通过事件 Schema 校验，并仍需用户确认后才正式入账。

### 语音输入

- 只有用户点击“开始录音”后才申请麦克风权限，不做后台录音或自动采集。
- 支持浏览器实时中文转写，转写内容可在提交前手动修订。
- 不支持 Web Speech API 的浏览器仍可录音或选择录音文件；配置 `STT_PROVIDER=openai_compatible` 后，可通过后端兼容 Whisper 的接口完成转写，也可以手动填写文字。
- 原始录音以 `voice` 媒体附件保存，转写单独写入 `speech_transcripts`。
- DeepSeek 只解析转写文字，不接收原始音频；解析结果仍需确认后才正式入账。
- 开发环境默认保存在 `backend/uploads`；配置媒体密钥后使用每对象数据密钥的 AES-256-GCM 信封加密。生产环境配置校验强制使用私有 S3 兼容对象存储、独立密钥和 ClamAV 扫描。

浏览器实时转写能力依赖具体浏览器实现，推荐使用最新版 Chromium。后端 STT 只在用户明确点击后发送本次录音，不后台采集；供应商、模型和超时均由环境变量配置。

### 组合内容与媒体附件

- 一条记录可以同时包含多段说明文字、多段原始录音以及多张图片、截图和视频。
- 文字块与媒体块都可重排；原始顺序写入 `raw_entry_contents`，附件不会混进事件 JSON。
- 草稿恢复后可以继续追加文字，系统会保留原候选历史并重新生成待确认候选。
- 图片、截图和视频只作为用户主动提供的原始证据保存，不执行 OCR、画面识别或多模态推断。
- 单个附件默认上限为 25 MB，单条记录默认最多 12 个媒体文件、总计 100 MB；可通过 `MEDIA_MAX_BYTES`、`MEDIA_MAX_FILES` 和 `MEDIA_MAX_TOTAL_BYTES` 调整。
- 草稿恢复和正式时间线均可预览附件；共享共同经历的其他成员看不到事件所有者的原始附件。
- 媒体接口要求登录且校验附件所有者；删除草稿时数据库附件记录、定位和本地存储文件会一起撤销或清理。
- 存储适配器支持私有 S3 兼容服务；对象不开公开 URL，并在 S3 服务端加密之外再进行应用层信封加密。读取仍通过登录态和所有者校验的短期请求返回。
- `MEDIA_SCAN_MODE=clamav` 时，附件在加密和保存前通过 ClamAV `INSTREAM` 扫描；感染或扫描服务异常都会拒绝保存。生产配置不允许关闭扫描。

### 主动定位

- 只有点击“添加位置”后才申请浏览器定位权限，不后台跟踪位置。
- 定位和文字、语音可以组合提交；用户可以给坐标填写“商店 A”等地点标签。
- 每个 AI 候选事件都要单独确认“事情发生在这里”“只是在这里记录”或“与这件事无关”。
- 精确坐标保存在私密事实层；DeepSeek 只接收用户填写的地点标签和位置角色，不接收经纬度。
- 匿名地点匹配默认关闭。用户开启后只使用约一公里的粗粒度网格，且敏感地点会被后端强制排除。
- 删除草稿会同步软删除原始定位并撤销匹配资格。

### 多用户账户

- 首次打开网页会进入注册/登录页，记录、草稿、媒体、时间线和图谱均按登录用户隔离。
- 密码使用带独立随机盐的 `scrypt` 派生值保存，不保存明文密码。
- 登录态使用随机不透明令牌；数据库只保存令牌摘要，浏览器通过 `HttpOnly`、`SameSite=Lax` Cookie 持有原令牌。
- 生产环境必须配置 `AUTH_COOKIE_SECURE=true` 并通过 HTTPS 提供服务。
- 本地已有的 `traceweave-dev` 开发数据可在开发环境注册同名账户后继续使用；生产环境不允许认领无凭据账户。

### 全局关系图谱与个人图谱

- 导航中的“关系图”是核心入口；“世界”视图展示全站活跃用户、明确设为公开的事件，以及这些公开事件连接的非敏感标准实体。
- 世界关系视图聚合为“用户 → 公开地点/事物”，事件视图展示“用户 → 公开事件 → 公开地点/事物”的证据链。未公开事件不会进入世界图。
- 世界图只展示事件标题、活动类型、按天降精度的时间和安全标准实体，不展示原始文字、附件、精确坐标、私人别名或未确认人物。
- “我”视图从当前用户的全部已确认事件实时构建，不读取待确认草稿，也不受公开可见性限制。
- 聚合关系视图展示用户与人物、地点、食物、书、歌曲、App 等事物的长期关系强度。
- 事件证据视图展示“用户 → 事件 → 人物/地点/事物”的可解释链路，点击节点可以查看关系及证据数量。
- 匿名关系发现与世界图是两条独立数据链：公开可见控制世界展示，关系匹配授权控制匿名推荐，两者互不替代。

### 匿名关系发现

- “发现”默认关闭，只有用户主动开启后才会为已确认事件生成社交投影。
- 投影仅包含标准实体、粗粒度地点、特征类型、权重、策略版本和不透明证据引用，不包含原文、附件、精确时间、精确坐标或私人别名。
- 两名用户都开启后，共同地点、食物、App、书籍、游戏和影音等标准实体可以形成匿名候选。
- 匹配分数同时考虑共同点数量和重复强度，并由 `SOCIAL_MATCH_MIN_SCORE` 配置最低阈值；默认不会因为一次普通共同点就推荐用户。
- 一方点击“愿意认识”后仍保持匿名；双方都同意才显示账户身份并建立连接。
- 关闭关系发现会撤销该用户的活动投影并使未连接候选立即失效；已经双方同意的连接独立保留，用户可主动断开。
- 匿名候选和已连接用户只进入当前用户的私有关系视图和“发现”页面，不会作为匿名节点混入公开世界图。

### 人物账户与共同经历

- 记录中的“小王”等人物首先仍是记录者的私有人物实体，不会仅凭姓名自动绑定平台注册账户。
- 事件所有者可以在时间线中输入对方完整用户名发送共同经历确认；被邀请人会在“发现”页看到邀请。
- 被邀请人接受后，人物实体才与账户身份连接，并创建双方接受的 `shared_occurrence`；共享事件进入双方时间线和图谱。
- 共享成员只能看到邀请中明确共享的事件标题、标准实体和日期级时间；原始文字、附件、私人实体、精确时间和精确坐标仍属于事件所有者。
- 接受共同经历的成员若也开启匿名关系发现，可以从该共同经历生成自己的最小化投影。因此 A 记录与 B 的共同经历、C 独立记录相同地点和对象时，C 可以分别与 A、B 形成候选关系。
- 邀请人可以撤回，被邀请人也可以退出；撤回会移除账户身份边、共享时间线和相关投影，图谱回退为原来的私人人物节点。

### 正式事件生命周期与分层隐私

- 已确认事件支持修改标题、类型、事实状态和起止时间，并使用事件版本做乐观并发控制，避免多个页面互相覆盖。
- 每次确认、修改和删除都会写入不可变的 `event_revisions` 快照；删除采用事实层软删除，并同步撤销共同经历、账户人物关联、图谱证据和社交投影。
- 单一隐私求值器按系统强制规则、事件、实体、活动类别、用户默认解析内容可见范围、匿名统计、匿名匹配、身份披露和共同经历授权，并显示每项决策来源。“完全隔离”会强制关闭全部派生用途。
- 收回匹配或共同经历授权后，已有邀请、共享时间线和关系证据会立即失效，而不是只影响之后的新数据。

### 候选纠错与实体记忆

- AI 候选确认页支持修正标题、类型、事实状态、开始/结束时间、时区、时间精度和原始时间表达。
- 参与人和实体可增删；可修改角色、类型、数量、单位、金额、币种、主观感受、实体属性和事件扩展字段。
- 候选中的人物和事物可以明确选择已有长期实体；否则按规范名称和已确认别名自动复用。
- 候选可以逐条拒绝、拆成多件或把多个候选合并为一件；确认请求会明确列出所有接受和拒绝结果，不能把未处理候选静默入账。
- AI 原值、用户最终值及字段级差异会写入反馈记录，拆分和合并保留来源候选 ID。
- “实体记忆”页支持搜索、重命名、添加别名、同类型实体合并、按证据拆分及撤销。合并会转移事件证据、别名和隐私策略，撤销会恢复原引用。
- 人物实体也进入统一隐私求值，敏感人物/地点与普通物品使用同一决策入口，不会绕过实体策略。

### 搜索、洞察与社交圈

- 时间线支持关键字、日期、类型、人物、地点、实体筛选和分页；事件详情可追溯原始内容块、转写、附件、修订历史及字段来源。
- 正式事件的参与人、实体关系、数量金额、地点和扩展字段可以在确认后继续纠正，修改会产生新版本和审计快照。
- “回顾”明确分开保存用户声明与系统推断。推断带证据、模型/规则版本、置信度、衰减和到期时间，用户可以确认、否定或隐藏。
- 地点圈和兴趣圈只从允许参与匿名统计的标准实体生成；群体统计至少需要 3 名不同用户，避免小样本反推个人。
- 好友、圈子和公开内容流通过统一隐私策略读取；发现页提供屏蔽、举报、频率限制和关系撤权。
- 好友与私聊支持账号搜索、申请/同意/拒绝/撤回、统一好友列表、一对一文字会话、未读/已读、消息通知，以及解除或拉黑后的即时禁发；聊天内容不会自动进入 AI、时间线或图谱。
- 共同经历允许受邀者关联自己的既有事件，并由每位成员分别授权标题、标准实体、日期级时间和粗位置。

### 数据导出、删除与可靠任务

- “我的数据”页可导出账户的原始记录、AI 候选、正式事件、实体、位置、隐私、关系和审计数据。JSON 当前包含媒体完整元数据但不内嵌二进制附件。
- 永久删除必须同时输入当前用户名和密码。受理后立即冻结账号并撤销全部会话，后台删除数据库生活数据、登录凭据、社交关系和本地媒体文件，最后仅保留不可登录的匿名墓碑与作业审计。
- Outbox 和删除消费者使用数据库租约、`FOR UPDATE SKIP LOCKED`、幂等处理、指数退避、最大尝试次数和死信状态；进程重启后会继续处理未完成任务。
- `npm run restart` 会先执行增量数据库迁移，再启动前后端并等待健康检查，避免新代码先于 Schema 运行。

### 草稿提醒

- 未确认或解析失败的草稿都会按照用户设置写入待提醒时间，后台任务将到期提醒幂等地生成到 `notifications`。
- 提醒页面支持 1 小时到 7 天的常用延迟，并保留可扩展到 30 天的服务端配置范围。
- 浏览器系统通知必须由用户点击开启后才申请权限；配置 VAPID 后会注册标准 Web Push，页面关闭后也可收到通知。即使系统通知被拒绝，应用内提醒仍然可用。
- 确认或删除草稿会同步撤销提醒，不会继续发送已经失效的通知。

### 自然语言查询与周期回顾

- “回顾”页支持询问次数、金额、最近一次、实体排行和事件明细，并展示 AI 对问题的查询理解。
- DeepSeek 只把问题转换为固定枚举的查询 DSL，不接收用户历史数据，也不能生成或执行 SQL；服务端只使用白名单查询模板访问当前账户的正式事件。
- “本周”“上个月”“最近 7 天”等相对时间由后端根据用户时区确定性计算，不依赖模型自行计算日期边界。
- 周报和月报由正式事件确定性生成，包含事件数、活跃记录日、上周期对比、生活类型构成、高频实体、明确记录的金额和最近事件。
- 每次 AI 查询解释都会写入审计，明确标注数据范围为“问题文本”，事件、附件和原始记录均不发送给模型。

## 常用命令

```bash
npm run dev              # 同时启动前后端
npm run restart          # 后台重启前后端并等待健康检查
npm run services:stop    # 停止后台服务
npm run services:status  # 查看后台服务状态
npm run services:logs    # 查看前后端最近日志
npm run dev:frontend     # 只启动 Web
npm run dev:backend      # 只启动 API
npm run build            # 构建/检查两个 workspace
npm run test             # 运行测试
npm run db:migrate       # 执行增量迁移
npm run db:seed          # 创建本地开发用户和默认私密策略
npm run db:seed:graph-demo -- whyisee  # 为指定账号生成可重复执行的关系图演示数据
npm run db:seed:world-entities  # 幂等初始化常用标准实体与全局安全别名
npm run world:sync       # 立即同步实体目录并完整对账公共世界图投影
npm run backup           # 创建加校验和的 PostgreSQL 自定义格式备份
npm run backup:verify -- <目录> # 校验备份文件与归档目录
npm run load:smoke       # 对健康接口执行可配置并发冒烟
```

`pg_dump` 的主版本不能低于数据库服务器。若数据库运行在容器中，可在 `backend/.env` 配置 `TRACEWEAVE_PG_DUMP_CONTAINER=容器名`；备份会记录所用工具链，校验脚本自动使用同一容器中的 `pg_restore`。

## 当前实现（2026-08-11）

- PostgreSQL `zi_tw` 核心事实模型及 16 个增量迁移。
- 原始记录、AI 候选、用户确认、正式事件四层数据边界。
- 30 条待确认草稿上限和提醒任务数据模型。
- 事件参与者、用户实体、全局标准实体与事件关系落库。
- 共同经历、分层隐私策略、社交投影、双向同意与 Outbox 基础表。
- 文本记录 → DeepSeek JSON 事件抽取 → Schema 校验 → 用户编辑确认 → 时间线的端到端纵切。
- 主动录音/选择录音 → 可修订转写 → DeepSeek 解析 → 用户确认 → 语音草稿回放与删除清理。
- 文字/语音与图片、截图、视频组合提交 → 附件独立校验和私密存储 → 草稿恢复 → 正式时间线预览 → 删除清理。
- 主动定位 → 地点标签/精度/敏感级别落库 → 逐事件地点确认 → 私密地点边和可选粗粒度社交匹配。
- 用户注册、登录、退出、持久会话及所有业务接口的账户级数据隔离。
- 世界公共图投影、Outbox 实时刷新、默认每小时实体目录同步与完整对账；个人关系聚合图和事件证据图继续读取账户完整事实。
- 显式授权的社交投影、匿名共同特征匹配、单方意愿等待、双向身份披露、连接与断开流程。
- 私人人物到账户的邀请确认、共同经历时间线、双向账户图谱边及可撤销的共享成员投影。
- 正式事件的版本化修改、软删除、修订历史，以及对共享经历和派生图谱的级联撤销。
- 事件级五维授权、“完全隔离”策略与实时撤销。
- 用户默认、活动类别、实体和事件四层隐私管理，以及五个独立授权维度的统一求值与来源解释。
- 完整候选字段纠错、逐条拒绝、候选拆分/合并、字段级反馈、长期实体选择、别名复用，以及实体合并/拆分/撤销。
- 可靠 Outbox 消费、失败重试/死信、账户 JSON 导出、密码确认删除与异步删除编排。
- 草稿到期扫描、应用内提醒、用户主动开启的 Web Push 和提醒偏好。
- DeepSeek 受限查询 DSL、账户隔离的确定性查询，以及按用户时区生成的周报和月报。
- 时间线复合搜索、事件完整溯源、关系字段二次编辑、用户声明、证据衰减推断、趋势和异常回顾。
- 可逐项授权的共同经历成员模型、好友/圈子/公开内容读取、匿名圈子统计、屏蔽和举报。
- 用户搜索与好友申请、统一社交连接、好友列表、一对一文字私聊、未读/已读、消息提醒与数据导出/删除清理。
- 指标端点、CI、数据库备份校验和轻量负载冒烟脚本。

当前已经接入 DeepSeek 文本事件解析、浏览器/可选后端主动语音转写和组合内容。开发环境使用本地私密媒体存储适配器，并保留明确标识的规则解析器作为开发模式。生产部署仍必须提供真实私有 S3/KMS、ClamAV、VAPID、后端 STT（若启用）、HTTPS、监控告警与备份保留设施；仓库已提供适配器和配置校验，但外部服务不能在缺少凭据时假装完成验收。
