## 详情页正文空白：根因与修复（实测确认）

- 现象：详情页标题正常，正文区整片黑，时好时坏。
- 取证：`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + CDP `Runtime.evaluate` → DOM 有 243 字符、body 尺寸 328×604 正常，但屏幕 0 亮像素 → **渲染层问题，不是数据问题**。
- 修两处（`lib/features/topic/widgets/article_webview.dart`）：
  1. **改用 Hybrid Composition**：`WebViewWidget.fromPlatformCreationParams(AndroidWebViewWidgetCreationParams(displayWithHybridComposition: true))`。默认 TLHC 把 WebView 画到 SurfaceTexture，部分设备不刷新。
  2. **高度抖动**：JS 原来 `Math.max(body.scrollHeight, documentElement.scrollHeight)`，`documentElement` 至少等于视口高 → 父级撑高后把视口高报回来，自锁成 7680。改成只量 body + `innerWidth<60` 不报 + Dart 侧 120ms debounce。
- 验收（不截图交付，用像素断言）：正文核心区亮像素占比，空白 0.00% / 正常 5~8%。3 篇文章 + 同篇往返 5 次全部 8% 左右；高度日志只报正确值。
- 顺带：`body > :first-child { margin-top: 0 }` 消除 margin 折叠导致的顶部 22px 空隙。
- 副作用已查：SurfaceView 未盖住底部 tab 栏。
- 调试技巧留档：`adb exec-out screencap -p` + PIL 统计区域亮像素，是判断"空白/有内容"最省事的断言手段。
