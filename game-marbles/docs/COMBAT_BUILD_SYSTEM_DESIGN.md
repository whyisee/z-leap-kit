# 战斗 BD 深度系统设计

## 1. 背景

当前战斗构筑主要由三部分组成：

- 出战角色与角色携带的弹珠。
- 局内升级时随机出现的 3 张战术升级卡。
- 角色等级、技能、被动、弹珠等级等局外成长。

问题是玩家能主动控制的内容偏少。角色和弹珠决定了大方向，但进入战斗后，战术升级随机性较强，玩家很难稳定围绕一个目标构筑。最终体验容易变成“抽到什么用什么”，BD 深度不够清晰。

本方案目标是把战斗构筑拆成 4 个互相联动的系统：

- 卡组配置：玩家决定本局主要会抽到哪些战术卡。
- 核心质变卡：让流派出现真正的玩法变化，而不是只堆数值。
- 出战阵法：开战前选择流派入口，影响局内成长方向。
- 角色与弹珠羁绊：让阵容组合解锁额外规则和专属卡。

## 2. 设计目标

- 让玩家开战前就能表达“这局想玩什么流派”。
- 保留随机三选一的乐趣，但降低完全失控的挫败感。
- 让战术升级从“数值奖励”变成“流派成长路径”。
- 让角色、弹珠、阵法、卡组之间产生可读、可规划的联动。
- 第一版尽量复用现有 `upgradeCards`、`familyId`、`tag`、`requires`、`tacticState` 等结构，避免推翻重做。

## 3. 总体战斗构筑流程

### 3.1 开战前

玩家在作战终端内完成以下配置：

1. 选择出战角色。
2. 给角色配置弹珠。
3. 选择出战阵法。
4. 选择或自动生成战术卡组。
5. 查看已激活的羁绊效果和推荐流派。

系统根据以上配置生成本局的 `battleBuild`：

- `formationId`：当前阵法。
- `deckId` 或 `deckCardIds`：本局战术卡组。
- `activeBondIds`：已激活羁绊。
- `buildTags`：本局主标签，例如反弹、燃烧、爆炸、控制、连锁、多弹、Boss。
- `coreProgress`：核心质变卡进度。

### 3.2 局内升级

升级时仍然展示 3 张卡，但来源变得更可控：

| 槽位 | 来源 | 作用 |
| --- | --- | --- |
| 1 | 卡组槽 | 优先从玩家配置的卡组中抽取 |
| 2 | 阵法/羁绊槽 | 优先出现阵法或已激活羁绊相关卡 |
| 3 | 野牌槽 | 从全局可用池中抽取，保留惊喜和变数 |

如果当前流派核心进度达到阈值，下一次升级至少出现 1 张核心质变卡或核心强化卡。

### 3.3 局内成长闭环

完整闭环如下：

1. 角色 + 弹珠决定基础标签。
2. 阵法强化某类标签和局内规则。
3. 羁绊解锁专属被动和专属卡。
4. 卡组提高目标卡出现率。
5. 选择同流派卡积累核心进度。
6. 核心质变卡改变玩法。
7. 后续卡围绕核心继续强化。

## 4. 卡组配置系统

### 4.1 基本规则

战术卡组是玩家开战前配置的一组战术卡。局内升级不再完全从全量卡池抽取，而是优先从卡组中抽取。

建议第一版规则：

- 每套卡组 18-24 张卡。
- 同名卡只能放 1 张，叠加次数仍由局内抽取和 `maxStacks` 控制。
- 卡组至少包含：
  - 8 张通用卡。
  - 6 张流派卡。
  - 2 张生存或功能卡。
  - 2 张角色、弹珠或羁绊相关卡。
- 未解锁卡不能放入卡组。
- 关卡禁用卡、PVP 禁用卡不能放入对应模式卡组。

### 4.2 卡组来源

卡可以来自不同池：

| 池 | 说明 | 示例 |
| --- | --- | --- |
| 通用池 | 所有阵容都可使用 | 火力校准、快速装填、弱点测算 |
| 流派池 | 绑定某类玩法标签 | 反弹增幅、余烬扩散、电弧延展 |
| 角色池 | 上阵指定角色后可用 | 工程师超频、爆破补给 |
| 弹珠池 | 装备指定弹珠后可用 | 分裂强化、低温制动 |
| 羁绊池 | 激活指定组合后可用 | 灼爆协同、折射工坊 |
| 关卡池 | 由章节、Boss 或活动加入 | Boss 猎手、完美撤离 |

### 4.3 自动组卡

为了降低门槛，系统需要提供自动组卡：

- 按当前阵容推荐。
- 按阵法推荐。
- 按最近胜利卡组推荐。
- 按新手安全卡组推荐。

自动组卡不应该追求最优，而是保证“可用、成型、有核心方向”。

### 4.4 卡组 UI

卡组配置页建议展示：

- 左侧：当前阵法、角色、弹珠、羁绊预览。
- 中间：当前卡组列表，按标签分组。
- 右侧：可加入卡池，支持按标签、稀有度、来源筛选。
- 底部：构筑摘要，例如“反弹 7 / 多弹 5 / 生存 3 / 核心候选 2”。

## 5. 核心质变卡

### 5.1 定义

核心质变卡不是普通数值提升，而是改变战斗规则、弹珠行为或击杀循环的关键卡。

普通卡示例：

- 全队伤害 +16%。
- 弹珠速度 +14%。
- 暴击率 +6%。

核心质变卡示例：

- 第 5 次反弹时释放一次小型分裂弹。
- 燃烧敌人死亡时爆炸并传播燃烧。
- 闪电命中减速目标时额外连锁 1 次。
- 场上弹珠数量越多，小弹珠持续时间越长。

### 5.2 核心类型

建议分为 3 类：

| 类型 | 说明 | 限制 |
| --- | --- | --- |
| 主核心 | 决定本局主玩法 | 每局最多 1 个 |
| 副核心 | 补强主玩法或形成混合流派 | 每局最多 2 个 |
| 核心强化 | 已拥有核心后的后续强化 | 按核心开放 |

### 5.3 核心出现条件

核心卡不建议完全随机出现，应由玩家选择和局内行为共同触发。

可用条件：

- 当前阵法匹配。
- 卡组中携带该核心。
- 已选择指定数量的同标签卡。
- 上阵指定角色或携带指定弹珠。
- 激活指定羁绊。

示例：

| 核心卡 | 条件 | 效果 |
| --- | --- | --- |
| 回环裂变核心 | 反弹标签卡 >= 3，携带基础或分裂弹珠 | 弹珠每第 5 次反弹释放 1 枚小型分裂弹 |
| 灼爆链核 | 燃烧 + 爆炸标签卡合计 >= 4 | 燃烧敌人死亡时产生小爆炸，并把燃烧扩散给附近敌人 |
| 静电冰环核心 | 闪电 + 控制标签卡合计 >= 4 | 闪电命中减速敌人时额外连锁，且刷新减速时间 |
| 弹幕增殖核心 | 多弹标签卡 >= 3，场上弹珠峰值 >= 16 | 小弹珠持续时间增加，并根据场上弹珠数量提高伤害 |
| 猎核协议 | Boss 标签卡 >= 2 或 Boss 波前获得 | 暴击精英/Boss 时返还最近角色技能冷却 |

### 5.4 核心进度

局内战术面板增加核心进度：

```text
灼爆链核
燃烧 2 / 爆炸 2 / 需要 4
下次升级：核心候选概率提高
```

当进度满时：

- 下一次升级至少出现一张可用核心卡。
- 如果核心卡没有被选择，进度保留，但保底消耗。
- 选择主核心后，其他互斥主核心不再出现。

## 6. 出战阵法系统

### 6.1 定义

阵法是开战前选择的流派入口。它不只是角色站位，也代表一套战斗倾向、卡池权重和局内规则。

阵法不应提供过强裸数值，重点是改变构筑方向。

### 6.2 第一批阵法

| 阵法 | 流派方向 | 效果 |
| --- | --- | --- |
| 回环阵 | 反弹 / 多弹 | 反弹类卡权重提高，弹珠首次反弹后伤害小幅提高 |
| 灼爆阵 | 燃烧 / 爆炸 | 燃烧、爆炸类卡权重提高，燃烧敌人受到爆炸伤害提高 |
| 磁控阵 | 闪电 / 控制 | 连锁、控制类卡权重提高，减速目标受到闪电伤害提高 |
| 猎核阵 | 暴击 / Boss | 暴击、Boss 类卡权重提高，精英/Boss 波前增加核心卡概率 |
| 坚守阵 | 生存 / 撤离 | 生存、防线类卡权重提高，基地低血量时获得额外刷新机会 |
| 赏金阵 | 经济 / 成长 | 经济、成长类卡权重提高，但前几波敌人强度略高 |

### 6.3 阵法影响项

阵法可以影响：

- 初始战术刷新次数。
- 指定标签卡出现权重。
- 核心质变卡进度来源。
- 敌人压力或奖励倍率。
- 角色站位或弹珠初始发射角。
- 自动战斗选卡偏好。

### 6.4 阵法解锁

阵法建议通过玩法进度解锁：

- 回环阵：默认解锁。
- 灼爆阵：拥有爆破手或燃烧弹珠达到 3 级。
- 磁控阵：拥有磁能师或闪电弹珠达到 3 级。
- 猎核阵：通关第 2 章 Boss。
- 坚守阵：守卫者解锁。
- 赏金阵：收藏室或商店相关进度解锁。

## 7. 角色和弹珠羁绊

### 7.1 羁绊类型

羁绊由当前出战角色、角色装备弹珠、队伍整体标签共同激活。

| 类型 | 条件 | 示例 |
| --- | --- | --- |
| 角色羁绊 | 指定角色同时上阵 | 工程师 + 棱镜师：折射工坊 |
| 角色弹珠羁绊 | 指定角色携带指定弹珠 | 爆破手携带爆裂 + 燃烧：热熔装药 |
| 弹珠标签羁绊 | 队伍携带指定标签组合 | 燃烧 + 爆炸：灼爆协同 |
| 三人队羁绊 | 三个角色满足职业或主题 | 工程师 + 磁能师 + 棱镜师：高频矩阵 |
| 阵法羁绊 | 指定阵法 + 指定组合 | 灼爆阵 + 爆破手 + 炼金师：熔炉协议 |

### 7.2 羁绊奖励层级

羁绊不只给一个固定属性，而是分三层：

1. 开局被动：小幅、稳定的效果。
2. 解锁卡：把羁绊专属卡加入本局可抽池。
3. 解锁核心：满足进度后出现专属核心质变卡。

### 7.3 羁绊示例

| 羁绊 | 条件 | 开局效果 | 解锁卡 / 核心 |
| --- | --- | --- | --- |
| 折射工坊 | 工程师 + 棱镜师 | 分裂弹珠存在时间 +0.25 秒 | 解锁“镜面复写”：反弹后有概率生成小弹珠 |
| 热熔装药 | 爆破手携带爆裂 + 燃烧 | 燃烧敌人受到爆炸伤害 +8% | 解锁“灼爆链核” |
| 静电冰环 | 磁能师 + 减速 + 闪电 | 减速目标受到闪电伤害 +10% | 解锁“静电冰环核心” |
| 坚壁压制 | 守卫者 + 减速弹珠 | 基地生命 +1，控制卡权重提高 | 解锁“底线火网强化” |
| 点金燃剂 | 财宝猎人 + 燃烧弹珠 | 燃烧击杀金币 +1，有上限 | 解锁“赏金燃爆”：金币越多爆炸越强 |
| 虚空裂解 | 虚空使 + 分裂 + 爆裂 | 爆炸有小概率牵引敌人 | 解锁“裂隙坍缩核心” |

### 7.4 羁绊可视化

作战终端中增加羁绊预览：

- 已激活：高亮显示，并展示效果。
- 接近激活：显示缺少哪个角色或弹珠。
- 不可用：灰显并显示解锁条件。

角色详情和弹珠详情中也展示相关羁绊入口。

## 8. 随机控制机制

为了让玩家不被随机性完全支配，建议补充以下控制手段：

| 机制 | 说明 |
| --- | --- |
| 刷新 | 消耗刷新次数，重抽 3 张卡 |
| 锁定 | 保留 1 张卡到下次刷新或下次升级 |
| 禁用标签 | 本局后续不再出现某个低优先级标签，次数有限 |
| 定向检索 | 下一次升级至少出现指定标签或指定核心候选 |
| 核心保底 | 核心进度满后，下一次升级必出核心候选 |
| 卡组槽保底 | 每次升级至少 1 张来自玩家卡组 |

第一版建议先实现：

- 卡组槽保底。
- 核心保底。
- 刷新。

锁定和禁用标签可以作为第二阶段。

## 10. UI 改造建议

### 10.1 作战终端

作战终端弹窗增加 4 个区域：

- 出战小队：当前角色和弹珠。
- 阵法选择：展示阵法图标、流派标签、解锁状态。
- 战术卡组：展示当前卡组和自动推荐按钮。
- 羁绊预览：展示已激活和接近激活的羁绊。

开始战斗按钮旁展示构筑摘要：

```text
灼爆阵 / 灼爆链核候选
燃烧 5 · 爆炸 4 · 生存 2
已激活：热熔装药、点金燃剂
```

### 10.2 战术升级面板

每张卡增加来源标识：

- 卡组
- 阵法
- 羁绊
- 核心
- 随机

面板顶部展示：

- 当前阵法。
- 当前核心进度。

### 10.3 战术面板

- 已选卡按流派分组。

## 11. 平衡原则

- 卡组配置提高稳定性，但不能让玩家只塞最强卡。通过卡组下限、来源限制、功能卡/生存卡要求控制。
- 核心质变卡改变玩法，但不要直接给过高数值。强度来自机制联动。
- 阵法提供方向，不应成为简单的高额伤害倍率。
- 羁绊效果第一层要轻，主要价值应在解锁专属卡和核心。
- 随机仍然保留，野牌槽用于制造惊喜和临场调整。
- PVP 中需要单独限制核心卡和羁绊卡强度，避免不可控滚雪球。

## 12. 第一阶段开发范围

第一阶段目标是做出可感知的 BD 深度，而不是一次性完成全部系统。

建议范围：

1. 新增战斗构筑状态 `battleBuild`。
2. 新增 3 个阵法：回环阵、灼爆阵、磁控阵。
3. 新增卡组配置，先支持系统预设卡组和自动推荐，不做复杂编辑器。
4. 改造 `generateChoices()`：
   - 第 1 张优先来自卡组。
   - 第 2 张优先来自阵法、羁绊或当前阵容标签。
   - 第 3 张保留随机。
5. 新增 6 张核心质变卡：
   - 回环裂变核心。
   - 灼爆链核。
   - 静电冰环核心。
   - 弹幕增殖核心。
   - 猎核协议。
   - 底线火网核心。
6. 新增 4 个羁绊：
   - 折射工坊。
   - 热熔装药。
   - 静电冰环。
   - 坚壁压制。
7. 战斗内战术面板显示阵法、核心进度和羁绊。

## 13. 第二阶段开发范围

- 卡组编辑器完整 UI。
- 锁定卡、禁用标签、定向检索。
- 更多阵法和羁绊。
- 核心强化卡链路。
- 图鉴中展示卡组、阵法、羁绊、核心卡。
- 后台内容设计器支持配置阵法、羁绊、核心卡。

## 15. 验收标准

第一版完成后，需要达到以下体验：

- 玩家开战前能明确选择一个流派方向。
- 同一套阵容选择不同阵法，局内升级体验明显不同。
- 至少 3 个流派能稳定成型。
- 每个流派至少有 1 张让玩法发生变化的核心质变卡。
- 升级三选一不再经常出现和当前阵容完全无关的卡。
- 战斗内能看懂当前 BD 的核心进度和羁绊来源。
