# 幻化抽卡系统设计

## 1. 模块定位

幻化抽卡是纯外观收藏系统，只提供角色外观、弹珠外观、战斗特效、展示动作、头像框、称号等内容，不提供任何数值强度。

系统目标：

- 增加长期收集目标，不破坏现有角色、弹珠、宝石、基地协议的数值平衡。
- 让玩家能通过外观表达阵容风格和弹珠流派。
- 给能源晶体、活动奖励、成就奖励提供稳定消耗与投放出口。
- 和图鉴、成就、商店形成闭环，但不强迫玩家为了通关抽卡。

硬性原则：

- 幻化不增加攻击、冷却、生命、金币、掉落、暴击、经验、关卡收益。
- 幻化不改变弹珠碰撞体积、碰撞判定、敌人可读性。
- 传说幻化可以更华丽，但必须支持战斗中特效简化。
- 重复抽取只转为外观兑换材料，不转为战斗资源。

## 2. 入口设计

新增一级入口：**幻化舱**。

### 2.1 基地主页入口

`幻化舱` 放在基地主页设施区，作为和编队舱、弹珠工坊、仓储库同级的功能入口。

| 入口 | 目标页面 | 视觉方向 | 入口状态 |
| --- | --- | --- | --- |
| 幻化舱 | 幻化抽卡 / 外观管理 | 展示舱、换装镜面、星盒彩球、弹珠投影 | 有免费抽、保底接近、可兑换时显示提示 |

入口交互：

- 点击 `幻化舱` 进入幻化主界面。
- 有免费单抽或活动赠券时，设施上显示轻量提示。
- 不在底部导航新增常驻按钮，避免底部导航过重。
- 底部导航仍保留基地、角色、弹珠、仓库、商店这类高频功能。

### 2.2 二级入口

| 来源 | 入口位置 | 行为 |
| --- | --- | --- |
| 角色详情 | `幻化` Tab 内的获取按钮 | 跳转到角色幻化池，并定位当前角色相关幻化 |
| 弹珠工坊 | `幻化` 区域的获取按钮 | 跳转到弹珠幻化池，并定位当前弹珠类型 |
| 补给站 | 外观商店 / 幻彩尘兑换 | 只做兑换和直购，不作为主抽卡入口 |
| 收藏室 | 幻化图鉴 | 查看已拥有、未拥有、来源和展示预览 |
| 成就奖励 | 奖励详情 | 发放幻化券或幻彩尘，引导去幻化舱 |

管理边界：

- `幻化舱` 只负责抽取、保底、抽卡演出、最近记录、卡池预览和幻彩尘兑换。
- `角色幻化` 的装备、切换、预览管理放在角色详情的 `幻化` Tab。
- `弹珠幻化` 的装备、切换、战斗特效配置放在弹珠工坊。

## 3. 页面结构

幻化主界面采用“抽卡舱”结构：

1. 左侧资源与卡池控制
   - 能源晶体
   - 角色幻化券
   - 弹珠幻化券
   - 幻彩尘
   - 当前卡池切换
   - 史诗 / 传说保底

2. 中央抽卡舱
   - 卡池主题
   - 抽卡机关演出
   - UP / 高稀有预览
   - 单抽 / 十连

3. 右侧状态与管理分流
   - 角色详情入口
   - 弹珠工坊入口
   - 抽卡记录

4. 下方卡池预览
   - 展示已拥有、未拥有、目标角色/弹珠
   - 支持幻彩尘兑换未拥有幻化
   - 不直接提供角色幻化装备按钮

基础布局：

```text
左侧：资源 / 卡池 / 保底
中部：幻化舱机关 / 高稀有预览 / 单抽 / 十连
右侧：管理入口 / 最近记录
下部：卡池藏品预览 / 幻彩尘兑换
```

## 4. 卡池类型

### 4.1 角色幻化池

产出内容：

- 角色皮肤
- 角色头像
- 角色出阵小人外观
- 入场动作
- 胜利展示
- 技能视觉表现

规则：

- 可以抽到未拥有角色的幻化。
- 未拥有角色的幻化进入仓库，角色解锁后自动可装备。
- 同一角色可拥有多个幻化。
- 装备幻化不改变角色技能数值和被动效果。

### 4.2 弹珠幻化池

产出内容：

- 弹珠本体外观
- 飞行拖尾
- 命中特效
- 爆炸、分裂、减速、闪电等特殊表现
- 弹珠专属音效皮肤

规则：

- 弹珠幻化按弹珠类型装备。
- 第一版只做全局配置，例如基础弹珠统一使用某个皮肤。
- 后续可以扩展为角色独立配置。
- 幻化不改变弹珠大小、速度、伤害、冷却、弹跳次数。

### 4.3 限时主题池

限时池用于活动和运营主题。

主题示例：

- 星海派对
- 废城涂装
- 熔火祭典
- 幽蓝数据季

限时池可以同时包含角色幻化和弹珠幻化，但页面上需要明确产出范围，避免玩家误抽。

## 5. 稀有度与表现

| 稀有度 | 角色幻化表现 | 弹珠幻化表现 |
| --- | --- | --- |
| 稀有 | 换色、材质、小头像 | 弹珠本体换色、小拖尾 |
| 史诗 | 新造型、入场小特效、技能特效替换 | 弹珠本体、拖尾、命中特效 |
| 传说 | 完整主题皮肤、专属展示动作、胜利表现、技能视觉 | 弹珠、拖尾、命中、击杀或爆炸特效、专属音效 |

传说幻化不应该靠大量粒子堆强度感，应该靠清晰主题、动作和独特色彩建立记忆点。

## 6. 抽取规则

建议概率：

| 稀有度 | 概率 |
| --- | --- |
| 稀有 | 82% |
| 史诗 | 15% |
| 传说 | 3% |

保底规则：

- 10 抽必出史诗或以上。
- 60 抽必出传说。
- 限时池保底继承到下一期同类型限时池。
- 角色幻化池和弹珠幻化池分别计算保底。
- 抽到传说后重置传说保底。

首版可以先不做复杂 UP 歪池，直接做：

- 角色幻化池：全角色常驻。
- 弹珠幻化池：全弹珠常驻。
- 限时主题池：主题幻化概率提升，未抽到主题时仍给常驻幻化。

## 7. 重复与兑换

重复抽取不返还金币、弹珠碎片、宝石等战斗资源，只转为 **幻彩尘**。

| 重复稀有度 | 转化 |
| --- | --- |
| 稀有 | 幻彩尘 10 |
| 史诗 | 幻彩尘 40 |
| 传说 | 幻彩尘 160 |

幻彩尘用途：

- 兑换指定常驻稀有幻化。
- 兑换旧主题幻化碎片。
- 兑换头像框、称号、展示背景。
- 活动结束后用于补齐少量主题兑换。

不建议让幻彩尘兑换角色等级、弹珠碎片、宝石或基地协议材料。

## 8. 货币与来源

新增资源：

| 资源 | 用途 | 来源 |
| --- | --- | --- |
| 角色幻化券 | 抽角色幻化池 | 活动、成就、图鉴奖励、能源晶体兑换 |
| 弹珠幻化券 | 抽弹珠幻化池 | 活动、成就、图鉴奖励、能源晶体兑换 |
| 幻彩尘 | 重复转化、外观兑换 | 重复幻化、活动奖励 |

能源晶体用途：

- 兑换幻化券。
- 购买限时外观礼包。
- 购买主题抽卡券组合。

金币不直接用于抽卡，避免成长资源和外观资源混在一起。

## 9. 装备与预览

### 9.1 角色幻化

角色详情新增 `幻化` Tab：

- 当前幻化
- 已拥有幻化列表
- 未拥有幻化来源
- 头像预览
- 出阵小人预览
- 技能视觉预览
- 装备按钮

装备规则：

- 只能给对应角色装备。
- 未拥有角色的幻化不能装备，但可以收藏。
- 默认皮肤永远保留。

### 9.2 弹珠幻化

弹珠工坊新增幻化区域：

- 按弹珠类型展示已拥有皮肤。
- 支持设置默认弹珠皮肤。
- 支持预览飞行拖尾和命中特效。
- 第一版不做角色独立配置，避免配置复杂度过高。

## 10. 战斗可读性限制

幻化特效必须遵守以下限制：

- 拖尾宽度不能超过弹珠直径的 1.5 倍。
- 命中特效持续时间建议不超过 0.35 秒。
- 爆炸类特效不能遮挡大面积敌人血条。
- 减速、燃烧、闪电等状态效果需要保留原本可读性。
- 设置页增加 `战斗特效强度`：低 / 中 / 高。
- PVP 或高密度关卡默认使用中或低强度显示。

## 11. 图鉴与成就联动

收藏室后续增加 `幻化` 分类：

- 角色幻化图鉴
- 弹珠幻化图鉴
- 限时主题图鉴
- 头像框和称号图鉴

图鉴奖励：

- 首次获得某个幻化可领取少量幻彩尘。
- 集齐某个主题可领取头像框、称号或展示背景。
- 不给战斗属性。

成就奖励：

- 首次十连。
- 获得第一个史诗幻化。
- 获得第一个传说幻化。
- 集齐某个角色的多个幻化。
- 集齐某个弹珠类型的多种外观。

## 13. 第一版范围

第一版建议只做最小闭环：

1. 基地主页新增 `幻化舱` 入口。
2. 幻化舱页面包含角色幻化池和弹珠幻化池。
3. 支持单抽、十连、券和能源晶体混合消耗、保底、重复转幻彩尘。
4. 角色详情可以装备角色幻化。
5. 弹珠工坊可以装备弹珠幻化。
6. 收藏室能查看幻化图鉴。
7. 设置里增加战斗特效强度。
8. 幻化舱提供抽卡演出和结果揭示。
9. 幻化舱卡池预览支持幻彩尘兑换，但不承载角色幻化装备管理。

首批内容建议：

- 角色幻化：每个角色 1 个稀有，核心角色先补 1 个史诗，先做 1 个传说样板。
- 弹珠幻化：每种弹珠 2 个稀有，1 个史诗，先做 1 个传说样板。
- 主题池先只做设计预留，不急着上线。

## 14. 验收标准

- 幻化舱作为主页设施入口出现，入口状态能提示免费抽或可领取。
- 抽卡产物不影响任何战斗数值。
- 重复幻化只转为幻彩尘。
- 保底进度可见。
- 抽卡演出可跳过，结果会进入最近记录。
- 幻彩尘可兑换指定常驻幻化。
- 角色和弹珠都能装备对应幻化。
- 角色幻化装备入口在角色详情，不放在幻化舱。
- 战斗中特效不遮挡关键敌人和血条。
- 构建通过，存档兼容旧玩家。
