# H5 弹珠打撤游戏设计方案

## 1. 项目定位

暂定名：**弹珠打撤**

这是一款面向移动端和网页端的 H5 轻度肉鸽弹珠游戏。玩家在 3-5 分钟内完成一局 20 波战斗，围绕 3 名角色、6 种弹珠、局内升级三选一和局外属性成长构筑不同打法。

核心体验目标：

- **短局高密度**：一局 3-5 分钟，每 8-15 秒完成一波选择或战斗反馈。
- **弹珠爽感**：弹珠反弹、穿透、分裂、爆炸、连锁，形成满屏碰撞和清场反馈。
- **角色协同**：每局 3 个角色同时上阵，每个角色发射 2 种弹珠，组合出队伍流派。
- **局内构筑**：一局可升级 5-10 次，每次 3 选 1，强化角色、弹珠、经济或生存。
- **局外成长**：游戏结束获得货币，用于提升全局属性和解锁新角色/弹珠。
- **轻量可重复**：不依赖复杂剧情和长流程，适合碎片时间随时玩。

## 2. 核心规则概览

| 模块 | 设计 |
| --- | --- |
| 单局时长 | 3-5 分钟 |
| 每局波数 | 固定 20 波 |
| 游戏速度 | 支持 1x / 2x / 4x |
| 上阵角色 | 每局 3 个角色 |
| 弹珠配置 | 每个角色 2 种弹珠，全队共 6 个弹珠槽 |
| 局内升级 | 经验升级，一局约 5-10 次 |
| 升级形式 | 每次升级 3 选 1 |
| 局外成长 | 结算货币，用于提升属性、解锁内容 |
| 胜利条件 | 击败第 20 波 Boss |
| 失败条件 | 基地生命归零，或敌人突破底线达到上限 |

## 3. 战斗核心循环

### 3.1 单局流程

1. 玩家选择或确认 3 名角色。
2. 每名角色携带 2 种弹珠。
3. 进入第 1 波战斗。
4. 角色自动按冷却发射弹珠。
5. 弹珠在场内反弹、命中敌人、触发特效。
6. 击败敌人掉落经验、金币和临时道具。
7. 经验满后暂停或半暂停，出现升级 3 选 1。
8. 玩家选择强化后继续战斗。
9. 每 5 波出现阶段压力点，第 20 波为 Boss。
10. 胜利或失败后进入结算，获得局外货币。
11. 玩家用货币提升属性，再开下一局。

### 3.2 战斗视角与场地

推荐竖屏优先，兼容 PC 居中布局。

- 逻辑画布：720 x 1280
- 顶部：波数、时间、金币、速度按钮、暂停按钮
- 中部：战斗区域
- 底部：3 名角色站位、技能能量、基地生命

战斗区域可理解为“弹珠防线”：

- 敌人从上方或多个入口进入。
- 敌人向下移动，试图突破底线。
- 角色位于底部，自动向场内发射弹珠。
- 弹珠撞墙反弹，命中敌人造成伤害。
- 弹珠存在持续时间、最大反弹次数或回收规则。

### 3.3 操作方式

基础操作尽量轻：

- 默认战斗自动发射，玩家主要负责升级选择和速度控制。
- 角色大招可作为主动技能，点击角色头像释放。
- 移动端使用大按钮，避免精细拖拽。
- PC 端支持鼠标点击和快捷键。

建议首版操作：

- 点击速度按钮：1x / 2x / 4x 循环切换。
- 点击角色头像：释放该角色主动技能。
- 升级时点击 3 张卡牌之一。
- 暂停菜单可退出、重开、调整音效。

## 4. 速度系统

游戏内提供 1 / 2 / 4 倍速。

### 4.1 设计目标

- 1x：适合新手观察和做选择。
- 2x：默认推荐速度。
- 4x：适合局外属性较高或重复刷局的玩家。

### 4.2 倍速影响范围

倍速影响：

- 敌人移动速度
- 弹珠飞行速度
- 发射冷却
- 技能持续时间流逝
- 波次刷新计时
- 粒子和掉落物动画

倍速不影响：

- 玩家选择升级的思考时间
- 暂停菜单
- 结算动画，可单独允许跳过

### 4.3 平衡限制

为了避免 4x 下失控：

- 升级时自动暂停战斗。
- Boss 释放关键技能前可短暂降速提示。
- 基地生命低于 30% 时，可闪烁提示但不强制降速。
- 4x 下命中特效可以减少粒子数量，保证性能。

## 5. 波次结构

每局固定 20 波，节奏按照“普通波 - 压力波 - 奖励波 - 精英/Boss”组织。

### 5.1 波次节奏表

| 波次 | 类型 | 目标体验 | 时长建议 |
| --- | --- | --- | --- |
| 1 | 教学/热身 | 快速清场，建立爽感 | 8-10 秒 |
| 2 | 普通 | 引入基础敌人组合 | 8-10 秒 |
| 3 | 普通 | 稳定掉落经验 | 8-12 秒 |
| 4 | 压力 | 敌人数量增加 | 10-12 秒 |
| 5 | 小精英 | 第一个强敌，保证升 1-2 级 | 12-15 秒 |
| 6 | 普通 | 新敌人类型 | 8-12 秒 |
| 7 | 普通 | 构筑开始成型 | 8-12 秒 |
| 8 | 奖励 | 金币怪/宝箱怪 | 8-10 秒 |
| 9 | 压力 | 高移速或护甲敌人 | 10-14 秒 |
| 10 | 精英 | 阶段 Boss，给高经验 | 15-20 秒 |
| 11 | 普通 | 中后期起步 | 8-12 秒 |
| 12 | 普通 | 混合敌人组合 | 8-12 秒 |
| 13 | 压力 | 远程/召唤类敌人 | 10-15 秒 |
| 14 | 奖励 | 高风险高收益 | 8-12 秒 |
| 15 | 精英 | 第二个阶段 Boss | 15-20 秒 |
| 16 | 普通 | 后期清屏爽感 | 8-12 秒 |
| 17 | 压力 | 敌人高血量 | 10-15 秒 |
| 18 | 压力 | 数量和速度叠加 | 10-15 秒 |
| 19 | 决战前 | 大量经验，最后成型 | 12-18 秒 |
| 20 | 最终 Boss | 验证构筑和局外强度 | 25-40 秒 |

目标总时长：

- 1x：约 5 分钟
- 2x：约 3.5-4 分钟
- 4x：约 2.5-3 分钟，适合刷局

### 5.2 波次生成规则

每波由以下参数生成：

- 敌人数量
- 敌人类型权重
- 敌人生命倍率
- 敌人移动速度倍率
- 掉落经验倍率
- 掉落金币倍率
- 特殊规则，例如护盾、分裂、冲刺、召唤

示例：

```ts
type WaveConfig = {
  wave: number;
  type: "normal" | "pressure" | "reward" | "elite" | "boss";
  durationTarget: number;
  enemyBudget: number;
  hpMultiplier: number;
  speedMultiplier: number;
  expMultiplier: number;
  coinMultiplier: number;
  enemyTags: string[];
};
```

### 5.3 难度曲线

每 5 波提高一个阶段：

- 1-5 波：让玩家理解队伍和弹珠。
- 6-10 波：要求至少形成一个强化方向。
- 11-15 波：敌人开始克制单一构筑。
- 16-20 波：考验输出、生存和范围能力是否平衡。

难度公式建议：

```txt
敌人生命 = 基础生命 * (1 + 波次 * 0.16) * 阶段倍率
敌人数量 = 基础数量 + floor(波次 * 0.7)
敌人速度 = 基础速度 * (1 + 阶段 * 0.08)
经验需求 = 基础需求 * pow(1.22, 当前等级 - 1)
```

## 6. 角色系统

每局 3 个角色同时上阵。角色负责发射弹珠、提供被动能力，并拥有一个主动技能。

### 6.0 当前版本角色页改版

角色页不再承担“全局强化”功能，而是作为角色收集和单角色养成入口。

当前实现拆分为：

- **角色列表**：展示已获取角色，点击后进入该角色详情。
- **角色详情**：展示角色等级、攻击估值、射速、技能冷却、主动技能和携带弹珠。
- **角色本体强化**：消耗金币提升角色等级，提供通用伤害、发射频率和技能冷却收益。
- **专属路线强化**：每名角色拥有 3 条不同路线，路线效果接入实际战斗公式。
- **出战阵容**：角色页提供 3 个上阵位，点击槽位后可用已获取角色替换该位置。
- **全局强化迁移**：原来的全局属性强化挪到“仓库 - 基地协议”，避免和角色系统混淆。

当前版本不做抽卡和碎片兑换，所有首批角色默认可用；存档结构已预留：

```ts
type CharacterProgress = {
  owned: boolean;
  level: number;
  routes: Record<string, number>;
};

type SaveData = {
  lineup: string[];
};
```

后续可以在此基础上扩展：

- 抽取/碎片解锁角色。
- 更细的编队限制，例如职业羁绊、费用上限、推荐阵容。
- 角色星级、皮肤、专属弹珠替换。
- 路线分叉互斥或高阶节点解锁。

当前可用 6 名角色：

| 角色 | 定位 | 弹珠 | 主动技能 | 路线方向 |
| --- | --- | --- | --- | --- |
| 工程师 | 多弹反弹 | 基础 / 分裂 | 折返板 | 射速 / 反弹 / 技能 |
| 爆破手 | 范围燃烧 | 爆裂 / 燃烧 | 高爆弹 | 爆炸 / 燃烧 / 循环 |
| 磁能师 | 连锁控制 | 闪电 / 减速 | 磁场 | 连锁 / 控制 / 技能 |
| 守卫者 | 防线压制 | 基础 / 减速 | 防线回收 | 穿透 / 防御 / 减速 |
| 棱镜师 | 连锁折射 | 闪电 / 分裂 | 棱镜齐射 | 连锁 / 分裂 / 技能 |
| 炼金师 | 燃烧回收 | 燃烧 / 爆裂 | 热核反应 | 燃烧 / 金币 / 爆炸 |

### 6.1 角色定位

每名角色包含：

- 基础属性：攻击、发射频率、暴击、技能冷却
- 两个弹珠槽：固定或可配置
- 被动技能：定义角色打法
- 主动技能：局内点击释放
- 局外等级：提升基础属性或解锁天赋

### 6.2 首批角色设计

#### 角色 A：工程师

定位：稳定输出、弹珠数量、适合新手。

- 弹珠 1：基础弹珠
- 弹珠 2：分裂弹珠
- 被动：每发射 12 颗弹珠，额外发射 1 颗小型追踪弹珠。
- 主动：部署 5 秒临时反弹板，让弹珠额外反弹并提高伤害。
- 局外成长：弹珠数量、发射频率、反弹伤害。

推荐构筑：

- 多弹珠
- 反弹增伤
- 分裂连锁

#### 角色 B：爆破手

定位：范围伤害、清杂、对密集波强。

- 弹珠 1：爆裂弹珠
- 弹珠 2：燃烧弹珠
- 被动：爆炸伤害命中 3 个以上敌人时，返还少量技能能量。
- 主动：向敌人最密集区域投放大爆弹，造成范围伤害并点燃。
- 局外成长：爆炸范围、燃烧伤害、技能充能。

推荐构筑：

- 范围爆炸
- 持续灼烧
- 击杀连爆

#### 角色 C：磁能师

定位：控制、连锁、对精英和 Boss 稳定。

- 弹珠 1：闪电弹珠
- 弹珠 2：减速弹珠
- 被动：被减速的敌人受到闪电伤害提高。
- 主动：生成磁场 6 秒，使场上弹珠轻微向敌人偏转。
- 局外成长：连锁次数、减速强度、控制时间。

推荐构筑：

- 闪电连锁
- 减速控制
- 对 Boss 增伤

### 6.3 后续角色方向

可作为二期内容：

- 赏金猎人：经济成长、金币转伤害。
- 赌徒：随机高收益、失败风险更高。
- 冰霜师：冻结、减速、延缓推进。
- 暗影客：暴击、穿透、斩杀低血敌人。
- 指挥官：强化全队、增加升级刷新次数。

## 7. 弹珠系统

每个角色发射 2 种弹珠。弹珠是构筑的主轴，不同弹珠决定队伍打法。

### 7.1 弹珠基础属性

每种弹珠包含：

- 基础伤害
- 发射间隔
- 飞行速度
- 存在时间
- 最大反弹次数
- 穿透次数
- 暴击率
- 特殊效果

### 7.2 首批弹珠设计

| 弹珠 | 定位 | 效果 | 克制 |
| --- | --- | --- | --- |
| 基础弹珠 | 稳定单体 | 无特殊效果，数值优秀 | 普通敌人 |
| 分裂弹珠 | 数量成长 | 第 3 次碰撞后分裂成 2 颗小弹珠 | 大量低血敌人 |
| 爆裂弹珠 | 范围清场 | 命中后造成小范围溅射 | 密集敌群 |
| 燃烧弹珠 | 持续伤害 | 命中后附加 3 秒燃烧 | 高血敌人 |
| 闪电弹珠 | 连锁输出 | 命中后弹跳到附近敌人 | 分散敌群 |
| 减速弹珠 | 控制 | 命中后降低敌人移动速度 | 高速敌人/Boss |

### 7.3 弹珠标签

为了支持升级系统，弹珠应带标签：

- `physical`：物理
- `explosive`：爆炸
- `elemental`：元素
- `chain`：连锁
- `control`：控制
- `multi`：多弹
- `boss`：对 Boss 特化

升级卡牌可以按标签作用于特定弹珠或队伍。

### 7.4 弹珠发射规则

基础规则：

- 每个角色独立计时。
- 每种弹珠有独立冷却。
- 角色会自动选择最近、最靠近底线或血量最高的敌人为目标。
- 弹珠初始方向带少量随机角度，避免轨迹完全重复。
- 弹珠触碰场地边界反弹。
- 弹珠存在时间结束后消失。

目标选择策略可被角色或升级修改：

- 最近目标
- 最低血量
- 最高血量
- 最靠近底线
- 敌人最密集区域

## 8. 敌人设计

敌人不是传统砖块，而是“可被弹珠碰撞攻击的移动目标”。为了保留打砖块爽感，敌人可以使用几何块状外观和碰撞反馈。

### 8.1 敌人基础属性

- 生命值
- 移动速度
- 碰撞半径或矩形尺寸
- 护甲
- 经验掉落
- 金币掉落
- 特殊能力

### 8.2 首批敌人

| 敌人 | 特点 | 设计目的 |
| --- | --- | --- |
| 小方块 | 低血、普通速度 | 基础清场对象 |
| 厚甲块 | 高血、低速、护甲 | 检验单体输出 |
| 快速块 | 低血、高速 | 检验控制和反应 |
| 分裂块 | 死亡后分裂 2 个小块 | 制造连锁爽感 |
| 护盾块 | 周期性减伤 | 鼓励爆发窗口 |
| 治疗块 | 为附近敌人回血 | 要求优先击杀 |
| 金币块 | 掉落大量金币 | 奖励波核心 |
| 精英块 | 高血，带技能 | 阶段压力 |
| Boss 核心 | 多阶段技能 | 最终验证 |

### 8.3 Boss 设计

第 20 波 Boss 应该有明确阶段。

Boss 示例：重装母舰

- 阶段 1：缓慢推进，召唤小方块。
- 阶段 2：生命低于 70%，生成护盾块保护自身。
- 阶段 3：生命低于 40%，周期性冲刺下压。
- 阶段 4：生命低于 15%，进入狂暴，速度和召唤频率提升。

Boss 奖励：

- 胜利给大量局外货币。
- 根据剩余基地生命给额外评分奖励。
- 第一次击败可解锁新角色或新弹珠。

## 9. 局内升级系统

局内升级是每局变化的核心。玩家通过击败敌人获得经验，一局升级 5-10 次。

### 9.1 经验节奏

目标：

- 第 1 次升级：第 2 波左右
- 第 2 次升级：第 4-5 波
- 第 3-4 次升级：第 7-10 波
- 第 5-7 次升级：第 11-16 波
- 第 8-10 次升级：第 17-20 波，取决于击杀效率和奖励选择

经验需求示例：

| 等级 | 需求经验 | 累计体验 |
| --- | --- | --- |
| 2 | 20 | 快速给第一次选择 |
| 3 | 34 | 初步确定方向 |
| 4 | 52 | 第一个流派节点 |
| 5 | 76 | 中期压力前强化 |
| 6 | 106 | 成型开始 |
| 7 | 142 | 后期强化 |
| 8 | 184 | Boss 前冲刺 |
| 9 | 232 | 高击杀奖励 |
| 10 | 288 | 强构筑专属 |
| 11 | 352 | 极限局可达 |

### 9.2 三选一卡牌类型

每次升级出现 3 张卡。卡牌可来自以下池：

1. 角色强化
2. 弹珠强化
3. 全队强化
4. 经济强化
5. 生存强化
6. 特殊机制

### 9.3 卡牌品质

| 品质 | 出现权重 | 效果强度 |
| --- | --- | --- |
| 普通 | 65% | 基础数值 |
| 稀有 | 25% | 明显改变效率 |
| 史诗 | 8% | 强构筑节点 |
| 传说 | 2% | 单局核心玩法变化 |

每 5 波后提升高品质权重。

### 9.4 卡牌示例

#### 通用输出

- 弹珠伤害 +15%
- 全队发射速度 +10%
- 弹珠飞行速度 +12%
- 暴击率 +5%
- 暴击伤害 +25%

#### 多弹流

- 工程师弹珠数量 +1
- 分裂弹珠额外分裂 1 次
- 小弹珠伤害 +30%
- 每存在 10 颗弹珠，全队伤害 +5%，最多 +30%

#### 爆炸流

- 爆裂弹珠范围 +20%
- 燃烧会在敌人死亡时扩散
- 爆炸命中 4 个以上敌人时触发二次爆炸
- Boss 受到燃烧伤害 +35%

#### 连锁控制流

- 闪电弹珠连锁次数 +2
- 减速弹珠减速效果 +15%
- 被减速敌人受到所有伤害 +12%
- 磁场持续时间 +2 秒

#### 生存

- 基地生命 +1
- 敌人靠近底线时受到伤害 +20%
- 每波结束恢复 1 点基地生命，最多触发 3 次
- 第一次致命突破时清屏并保留 1 点生命

#### 经济

- 本局金币获得 +25%
- 奖励波金币块数量 +50%
- 每次升级立即获得金币
- 当前金币每 100 点提高 1% 伤害，最多 20%

#### 特殊机制

- 所有弹珠获得 1 次穿透
- 每第 7 次命中必定暴击
- 弹珠反弹后伤害递增 3%，最多 45%
- 角色主动技能冷却 -20%

### 9.5 卡池约束

避免出现无效选择：

- 没有爆裂/燃烧弹珠时，不出现纯爆炸卡，除非卡牌同时赋予爆炸能力。
- 没有减速弹珠时，不出现只强化减速的卡。
- 同类卡牌可以叠加，但需要显示当前层数。
- 关键流派卡可以设置前置条件和上限。

### 9.6 升级选择节奏

升级界面建议暂停战斗：

- 三张卡居中展示。
- 显示品质颜色、影响对象和数值。
- 支持消耗局内金币刷新一次。
- 选择后播放短动画，立刻回到战斗。

## 10. 局外成长系统

游戏结束获得货币，用于长期成长。

### 10.1 货币类型

首版建议只保留 2 种：

- 金币：常规升级，所有局都能获得。
- 核心碎片：击败精英/Boss 或完成任务获得，用于解锁角色和弹珠。

避免首版货币过多导致系统臃肿。

### 10.2 结算公式

```txt
基础金币 = 击杀金币 + 波次奖励 + Boss奖励
表现加成 = 剩余生命加成 + 通关加成 + 速度加成
最终金币 = 基础金币 * (1 + 表现加成)
```

建议：

- 失败也给金币，但不超过通关的 40%-70%。
- 到达波数越高，结算越好。
- 4x 不应给过高收益，只给很小速度奖励或不给，避免强迫玩家高速。

### 10.3 属性升级

局外升级分 4 条线：

#### 全队属性

- 全队伤害 +2%/级
- 发射速度 +1%/级
- 暴击率 +0.5%/级
- 初始基地生命 +1/若干级

#### 角色强化

- 指定角色伤害 +3%/级
- 指定角色技能冷却 -1%/级
- 指定角色专属被动增强

#### 弹珠强化

- 指定弹珠伤害 +3%/级
- 指定弹珠特殊效果 +2%/级
- 指定弹珠存在时间 +1%/级

#### 功能成长

- 开局额外刷新次数 +1
- 升级卡牌稀有率 +1%
- 初始金币 +20
- 结算金币 +2%

### 10.4 局外成长控制

需要避免数值膨胀太快：

- 单项升级设置等级上限，例如 20 级。
- 升级消耗递增。
- 强属性分散在不同系统里，防止单一路线碾压。
- 前 30 分钟成长明显，之后逐渐转向解锁和构筑深度。

## 11. 队伍与构筑

每局 3 名角色，合计 6 种弹珠，是游戏的策略核心。

### 11.1 默认首发队伍

首版默认队伍：

1. 工程师：基础弹珠 + 分裂弹珠
2. 爆破手：爆裂弹珠 + 燃烧弹珠
3. 磁能师：闪电弹珠 + 减速弹珠

这样能覆盖：

- 单体
- 范围
- 持续伤害
- 连锁
- 控制
- 多弹

### 11.2 构筑方向

#### 多弹反弹流

核心角色：工程师  
核心卡牌：分裂次数、弹珠数量、反弹增伤  
优势：清屏爽感强，成长直观  
弱点：对高护甲 Boss 可能乏力

#### 爆炸燃烧流

核心角色：爆破手  
核心卡牌：爆炸范围、燃烧扩散、击杀连爆  
优势：清杂能力强，对密集波舒服  
弱点：遇到分散高速敌人效率下降

#### 闪电控制流

核心角色：磁能师  
核心卡牌：连锁次数、减速增伤、磁场持续  
优势：稳定，对精英和 Boss 好用  
弱点：前期爆发和金币波清理较弱

#### 经济滚雪球流

核心角色：后续赏金猎人，或通用经济卡  
核心卡牌：金币增伤、奖励波加成、升级返钱  
优势：中后期上限高  
弱点：前期选择经济卡会降低即时战力

### 11.3 组合协同

卡牌应鼓励跨角色配合：

- 减速敌人受到燃烧伤害提高。
- 爆炸命中被闪电标记的敌人时额外连锁。
- 分裂弹珠命中燃烧敌人时延长燃烧。
- 磁场期间所有弹珠获得轻微追踪。

## 13. 失败与胜利

### 13.1 失败条件

任一条件触发即失败：

- 基地生命降为 0。
- Boss 狂暴倒计时结束仍未击败。

敌人触底规则：

- 普通敌人触底：基地生命 -1。
- 精英触底：基地生命 -2。
- Boss 触底或完成突破技能：基地生命 -3。

### 13.2 胜利条件

击败第 20 波 Boss 后胜利。

胜利结算展示：

- 通关用时
- 击杀数
- 达到等级
- 获得金币
- 获得核心碎片
- 最高伤害角色
- 本局核心卡牌

### 13.3 评价系统

可选评分：

- S：通关且基地生命 >= 8
- A：通关且基地生命 >= 5
- B：通关
- C：到达 15 波
- D：到达 10 波

评分影响少量额外金币，不影响核心进度。

## 15. 新手体验

前 3 局应尽量顺滑。

### 15.1 第 1 局

- 默认 1x 或 2x。
- 前 5 波难度较低。
- 第一次升级固定出现容易理解的卡牌：
  - 弹珠伤害 +15%
  - 发射速度 +10%
  - 基地生命 +1
- 引导点击倍速按钮。
- 第一次技能满能量时提示点击角色头像。

### 15.2 第 2 局

- 解锁或展示局外升级。
- 引导升级一次全队伤害。
- 开始出现奖励波和精英波。

### 15.3 第 3 局

- 引导玩家理解流派。
- 升级界面显示推荐标签，例如“爆炸流”“控制流”。

## 17. 模式设计

### 17.1 标准模式

默认模式：

- 20 波
- 3-5 分钟
- 获得完整结算奖励

### 17.2 困难模式

二期内容：

- 敌人生命 +30%
- 敌人速度 +10%
- 高品质升级卡概率 +5%
- 结算金币 +25%

### 17.3 无尽模式

二期内容：

- 第 20 波后继续循环强化
- 每 5 波一个 Boss
- 排行榜可选
- 收益需要设置上限，防止刷爆经济

## 18. 美术与表现方向

### 18.1 视觉风格

建议方向：明亮街机科幻。

- 背景简洁，突出弹珠轨迹。
- 敌人使用高识别度几何块。
- 不同弹珠使用不同颜色和轨迹。
- 命中反馈要明显：闪光、数字、震动、碎片。

### 18.2 特效优先级

首版必须有：

- 弹珠轨迹
- 命中火花
- 敌人受击闪烁
- 敌人死亡碎裂
- 经验/金币飞向 UI
- 升级光效

后续增强：

- 屏幕轻微震动
- Boss 技能预警区域
- 高品质卡牌动画
- 通关结算爆发动画

### 18.3 性能策略

H5 移动端需要控制特效数量：

- 粒子使用对象池。
- 4x 下减少粒子数量。
- 同屏弹珠设置软上限，例如 120 颗。
- 伤害数字合并显示，避免满屏 DOM。
- 战斗 UI 尽量 Canvas 内绘制，菜单可用 DOM。

## 19. 音效设计

## 22. 原型验收标准

第一版原型达到以下标准即可进入调参阶段：

- 手机浏览器能完整打一局。
- PC 浏览器能完整打一局。
- 一局 3-5 分钟内结束。
- 玩家一局平均升级 5-10 次。
- 1x / 2x / 4x 切换稳定。
- 第 20 波 Boss 有明显压力。
- 失败也能获得局外货币。
- 局外升级后下一局能明显变强。
- 至少存在 3 种可感知流派：多弹、爆炸、控制。

## 23. 后续调参关注点

需要重点观察：

- 玩家是否总是选择同一种升级卡。
- 4x 是否变成唯一正确选择。
- 第 1-5 波是否太无聊。
- 第 15-20 波是否因弹幕太多导致性能下降。
- 局外成长是否过快让 20 波失去压力。
- Boss 是否只是在堆血，而没有机制差异。
- 经济卡是否值得选。
- 生存卡是否过弱或过强。

## 24. 推荐开发顺序

1. 搭建 Canvas 战斗循环。
2. 实现 3 名角色自动发射弹珠。
3. 实现敌人生成、移动、受击和死亡。
4. 实现 20 波流程和倍速。
5. 实现经验、升级、3 选 1。
6. 实现 6 种弹珠特殊效果。
7. 实现 Boss 和精英波。
8. 实现结算和局外金币升级。
9. 做移动端适配和性能优化。
10. 调整数值，让一局稳定在 3-5 分钟。

## 25. 设计风险

### 25.1 自动发射可能降低参与感

解决方式：

- 加入角色主动技能。
- 升级选择频率保持足够高。
- Boss 技能提供躲避或打断目标。

### 25.2 弹珠数量过多导致看不清

解决方式：

- 使用颜色区分弹珠。
- 合并伤害数字。
- 对小弹珠降低亮度。
- 设置同屏弹珠软上限。

### 25.3 局外成长压过局内构筑

解决方式：

- 局外提升主要提供基础效率。
- 局内升级提供玩法变化和爆发上限。
- Boss 按玩家局外强度适度缩放，或通过难度模式承接成长。

### 25.4 3 个角色信息量过大

解决方式：

- 首局固定队伍，不要求配置。
- 每个角色只展示 1 个头像、1 个技能按钮。
- 弹珠细节放在升级和图鉴里，不在战斗中塞太多文字。

## 26. 总结

这个方案的核心是把“弹珠打砖块”的碰撞爽感，改造成更适合 H5 的短局自动战斗体验：

- 3 名角色提供队伍协同。
- 6 种弹珠提供构筑基础。
- 20 波提供稳定节奏。
- 5-10 次三选一提供局内变化。
- 1/2/4 倍速适配不同玩家节奏。
- 局外货币升级提供长期目标。

首版最重要的是快速做出完整闭环，并把一局节奏压进 3-5 分钟。只要玩家愿意“再来一局”，后续再扩角色、弹珠、模式和养成都有空间。
